## Know where you stand_

We build **December Code**, a placement-readiness platform for final-year students in India. One diagnostic measures where you stand across 19 subjects and names exactly what to fix first. Then you practise with purpose, not at random.

Our first commit landed on **16 September 2026**: a walking skeleton with five subjects. We went live six days later, on **22 September**. As of 29 September 2026 there are **129 commits on `main`** and **19 subjects** live. ❄️

### `$ december --how`

```text
1. diagnose   one test across your subjects → a readiness score
2. locate     your primary gap and its root causes, topic by topic
3. practise   questions aimed at exactly what's weak
4. repeat     retake, and watch your readiness map fill in
```

### Subjects

**Core** · DSA · SQL · Aptitude · OOP · DBMS · Operating Systems · Computer Networks
**Languages** · Python · Java · JavaScript · C · C++ · C# · Go · Rust · Kotlin · PHP · Ruby · Swift

### The rules we build by

```yaml
# december.yml
streaks: false              # an empty day is just an empty day. No number to lose.
fake_numbers: never         # every figure on screen is computed from real data
placement_promises: never   # we measure readiness. We don't sell guarantees.
snippets: executed          # every code snippet runs on its official toolchain before it ships
formula: public             # how your score is computed → decembercode.tech/how-it-works
data_region: ap-south-1     # your data stays in Mumbai
```

### Under the hood

Next.js 14 · TypeScript · Tailwind CSS · Supabase Postgres · Vercel · Razorpay (UPI Autopay) · Resend
The app and the database both run in Mumbai (`bom1` / `ap-south-1`), because our students are in India.
